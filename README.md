# WorthIt AI Platform

WorthIt AI is a platform designed to help content creators understand their value and discover monetization and brand collaboration opportunities.

## Features

- Creator value assessment
- Brand collaboration opportunities
- Creator monetization insights
- Dashboard for creator information

## Technologies Used

- HTML
- CSS
- JavaScript
- API integrations

## Project

Built as a team project for a hackathon.

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Configure the required API keys according to the project's `.env.example` and setup instructions.

## Team

Developed collaboratively as a hackathon project.
