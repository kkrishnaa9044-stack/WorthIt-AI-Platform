## Project Overview

WorthIt is a web-based platform designed to connect content creators
and brands through an interactive collaboration ecosystem.

The platform provides creator profiles, brand dashboards, campaign
management tools, YouTube channel integration, and an AI-powered
assistant using Google's Gemini API.

## Local Development

Install Node.js and the Netlify CLI.

Run:

```bash
npx netlify dev
```

Open the local URL displayed in the terminal.

## Environment Variables

Create a `.env` file containing:

```env
YOUTUBE_API_KEY=your_youtube_api_key
GEMINI_API_KEY=your_gemini_api_key
GEMINI_MODEL=your_supported_model
```

Never commit API keys to version control.

## Deployment

The project is configured for deployment using Netlify.

1. Upload the project to GitHub.
2. Connect the repository to Netlify.
3. Configure the required environment variables.
4. Deploy the website.
5. Test the deployed features.

## Limitations

This project is a demonstration prototype.

Demo authentication is browser-based and should not be considered
secure production authentication.

AI functionality depends on external API availability.
